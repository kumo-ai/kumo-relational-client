# NVIDIA Nemotron Predict SDK Documentation

The NVIDIA Nemotron Predict SDK is the Python client for NVIDIA's structured-data foundation
model NIMs (Nemotron Tabular and Nemotron Relational), served behind the Universal TFM API.
